## Invariants & Test Assertions
### Invariants
- **[EK-JOURNAL]**: An acknowledged event is durably appended. Sequences are contiguous and strictly increasing within a journal, beginning at 1. The first event is manifest_admitted and pins the complete immutable manifest. All subsequent events name the same run, journal, and manifest digest. Events are never edited, deleted, resequenced, or backdated into an earlier prefix.
- **[EK-ATOMICITY]**: A locally authoritative operation commits its admitted input, idempotency record, authoritative effects, journal events, and replayable response as one owner-local durable effect before acknowledgement. Install referenced artifact bytes durably before that commit. Cross-owner publication remains asynchronous; this rule does not authorize a shared transaction across owners.
- **[EK-HASHES]**: Verify all content digests. At sequence 1, previous_event_hash is Missing(not_applicable). At sequence n>1 it equals event_hash at n-1. JournalPrefix.head_hash equals the event hash at last_sequence. Resolve an EvidenceRef by journal, sequence, event ID, hash, and JSON pointer; all must agree. A hash chain detects changed content but is not authentication.
- **[EK-PROVENANCE]**: The ingestion authority assigns producer identity, provenance, owner_domain, role, assertion_kind, event ID, sequence, receipt time, and hashes using authenticated producer registration and the manifest's event registry. Untrusted callers submit EventSubmission, never JournalEnvelope. Reject submitted server/provenance/authority fields rather than trusting them.
- **[EK-OBSERVATION]**: Producer IDs identify one sequence lifetime. Deduplicate identical (producer_id, producer_sequence) deliveries without duplicating effects. Conflicting content under that key is an integrity incident, not last-write-wins. Journal gaps, overflow, loss, flush receipts, and producer closure. A closed HTTP connection is not producer completeness or execution termination.
- **[EK-NULL]**: Every null is Missing(value=null, reason=<one of the six reasons>). Empty arrays mean an established empty collection, not unknown contents. Unknown semantic states remain explicit enums; false and zero are never missing-value sentinels. manual_override requires an authenticated journaled operator decision and preserves the superseded observation.
- **[OWD-LOCAL-COMMIT]**: Commit an owner's authorized effect, revision advance, and journal evidence atomically within that owner's durability boundary. Do not acknowledge before durability. No owner commit acquires a peer-owned write lock or waits for a peer transaction, acknowledgement, or large-payload serialization.

### 12.1 Manifest and producers

`Manifest` fields are:

`record_type`, `schema_version`, `manifest_id`, `run_id`, `journal_id`, `owner_domain`, `commissioner_id`, `activity`, `attempt`, `execution`, `task`, `task_semantic_hash`, `effective_configuration`, `environment`, `seed`, `build_pins`, `event_registry`, `producers`, `clocks`.

They pin the complete admitted scope, non-secret effective policy, actual execution identity, artifacts, registry, and clocks. Discovery uses inapplicable attempt. Manual mode has no automation subject.

`ExecutionDescriptor` contains `mode`, `subject`, `connector_version`, `binding_version`, and `assistance`. Kernel service mode applies to non-application work; application lifecycle permits only manual or subject.

`ProducerDescriptor` contains `producer_id`, `principal_id`, `owner_domain`, `role`, `provenance`, `sequence_required`, `allowed_event_kinds`.

`EventKindDeclaration` contains `event_kind`, `event_schema_version`, `role`, `assertion_kind`, `writer_roles`.

Producers cannot self-register authority or recycle sequence identities.

#### Reference: `seam-mappings/circus-tent-seam-mapping.md#122-event-ingress-and-envelope`

### 12.2 Event ingress and envelope

`EventSubmission` contains only `producer_sequence`, `event_kind`, `event_schema_version`, `occurred_at`, and `payload`. The channel supplies producer/run identity.

`EvidencePayload` contains `data`, `measurements`, `evidence_refs`, `artifact_refs`. All nested artifact identities appear in retention references.

`JournalEnvelope` contains:

| Fields | Authority |
|---|---|
| `record_type`, `schema_version` | Kernel record/version |
| `run_id`, `journal_id`, `manifest_hash` | Immutable admitted binding |
| `journal_sequence`, `event_id` | Journal authority |
| `event_kind`, `event_schema_version`, `role`, `assertion_kind` | Validated registry |
| `owner_domain`, `producer_id`, `provenance` | Authenticated producer registration |
| `producer_sequence` | Validated sequence or permitted missingness |
| `evidence_scope` | Ingestion-assigned current, historical-unscored, or synthetic |
| `recorded_at`, `occurred_at` | Receipt time and honest source time |
| `causal_refs`, `payload` | Validated support/content |
| `previous_event_hash`, `event_hash` | Verified hash chain |

Sequence 1 is `manifest_admitted`, with inapplicable predecessor. Events are contiguous, immutable, never backdated. Acknowledgement means durable append.

#### Reference: `seam-mappings/circus-tent-seam-mapping.md#123-dependency-order`

### 12.3 Dependency order

Install raw bytes, register receipt, register verification, construct normalized evidence, register normalized evidence, construct dependent transcript/publication, install/register it, then return references.

Nested claims/controls cite prior support, never their own future registration. Artifact bytes are retained while any retained manifest, prefix, diagnostic, replay, or archive depends on them.

Journal gaps, overflow, loss, flush receipts, and producer closure are explicit. Closed HTTP is not producer completeness.
