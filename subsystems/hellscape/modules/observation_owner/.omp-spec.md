### Invariants
- **[EK-PROVENANCE]**: The ingestion authority assigns producer identity, provenance, owner_domain, role, assertion_kind, event ID, sequence, receipt time, and hashes using authenticated producer registration and the manifest's event registry. Untrusted callers submit EventSubmission, never JournalEnvelope. Reject submitted server/provenance/authority fields rather than trusting them.
- **[EK-OBSERVATION]**: Producer IDs identify one sequence lifetime. Deduplicate identical (producer_id, producer_sequence) deliveries without duplicating effects. Conflicting content under that key is an integrity incident, not last-write-wins. Journal gaps, overflow, loss, flush receipts, and producer closure. A closed HTTP connection is not producer completeness or execution termination.
- **[EK-MANUAL]**: Manual execution has no automation subject, connector version, or binding version. It may produce genuine production observations and origin receipts. Human actions and notes retain manual provenance and disclosed assistance. An operator note alone cannot set an authoritative business predicate.
- **[EK-NULL]**: Every null is Missing(value=null, reason=<one of the six reasons>). Empty arrays mean an established empty collection, not unknown contents. Unknown semantic states remain explicit enums; false and zero are never missing-value sentinels. manual_override requires an authenticated journaled operator decision and preserves the superseded observation.
- **[LIFE-CLOSE]**: Active observation, transport connection, native execution, application mutation authority, and native context lifetime are distinct. On the local active deadline or end request, stop issuing workflow commands, record native-cancel availability and any attempt, record transport closure, and drain effects/evidence only within the commissioned bound.
- **[LIFE-LATE-EVIDENCE]**: Evidence received after observation closure is appended at the current journal head. Publish new owner revisions and a new report over new input pins; preserve every prior seal, publication, and diagnostic. A current snapshot may legitimately contain newer facts than its latest report used.
- **[LIFE-MANUAL]**: Manual mode requires no automation subject, native run ID, connector version, or native binding version. Its dispatch and execution slots stay at revision zero with not_applicable. The recorder owns observation and journals human actions with manual provenance.
- **[OWD-SESSION]**: Hellscape application state is reducer-owned; observation cannot set accepted data, identity verification, or commitment. The diagnostic domain cites exact application and observation input revisions and a journal prefix. It cannot amend either source to fit a finding.

### 7.1 EventSubmission

Untrusted ingress accepts only:

- Producer sequence.
- Event kind.
- Event schema version.
- Occurrence time or Missing.
- Evidence payload.

Authenticated registration supplies producer/run identity.

The authority assigns event ID, sequence, provenance, owner domain, role, assertion kind, receipt time, evidence scope, manifest hash, and chain hashes.

Caller-supplied authority fields are rejected.

#### Reference: `seam-mappings/hellscape-seam-mapping.md#7.4`

### 7.4 Sequence, loss, and completeness

| Condition | Required handling |
|---|---|
| New authorized sequence | Append once |
| Identical repeat | Return prior receipt; no duplicate effect |
| Same sequence/different content | Integrity incident; retain conflict |
| Out-of-order delivery | Track observed and missing ranges |
| Overflow | Record loss; never claim completeness |
| Flush without terminal sequence | Flush observed, completeness unresolved |
| Terminal sequence and no gaps | Complete |
| Connection close without terminal evidence | Incomplete or unknown |
| Late tail | Append at current head; revise assessment |

Telemetry batching is permitted. Destructive trailing debounce is not.

`ProducerCompleteness` contains producer ID, state, observed ranges, missing ranges, final sequence, and support.

Complete requires an evidenced final sequence and no unresolved gap. Zero final sequence means an evidenced empty producer lifetime.
