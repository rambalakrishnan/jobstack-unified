## Invariants & Test Assertions
### Invariants
- **[OWD-FETCH-IDENTITY]**: Lookup uses (target, job_id). For A_full, fetch identity is the actual listing source URL. For B, it is canonical URL, uppercase method, actual request-body digest, and representation-determining headers. Exclude ephemeral identity/session headers; do not exclude representation headers to increase cache hits.
- **[OWD-FETCH-NOOP]**: An absent root accepts an initial complete crawler domain without a predecessor archive. An existing identical fetch key makes the acquisition write a no-op. No archive is created for that no-op. Independent discovery, lease, classification, and semantic transitions may advance the crawler domain while preserving acquisition and replacement_lineage exactly.
- **[OWD-REVISION]**: A domain revision is a complete immutable snapshot, not a patch. revision=previous_revision+1 at the owner. The first revision is 1. The key (entity, domain, revision) identifies exactly one content digest. Identical retries are idempotent; different bytes under that key are an integrity conflict. Stale expected revisions or lease epochs cannot commit.

### Conformance Assertions

### 20.1 Fetch identity

\[
B=SHA256(JCS([target,"B",job\_id,canonical\_request]))
\]

\[
A\_full=SHA256(JCS([target,"A\_full",job\_id,listing\_source\_url]))
\]

Canonical request contains URL, uppercase method, actual body digest, and representation headers. Normalize scheme/host/default port, remove fragment, preserve query order unless proven irrelevant, and deterministically frame multivalue headers.

Exclude ephemeral identity/session headers, not representation-determining headers. Cookie rotation, run, date, response hash, and extractor version are not hidden inputs.

#### Reference: `seam-mappings/crawler-seam-mapping.md#20.2`

### 20.2 Same-key rule

Absent root accepts initial validated acquisition without predecessor archive.

Existing same key causes acquisition no-op and creates no replacement archive. Acquisition and replacement lineage remain unchanged. Independent discovery, lease, retry, classification, policy application, pipeline, semantic, and coverage-reference transitions may commit.

Changed response bytes under the same key are new observation evidence, not replacement content. A failed-render repair under the same key requires a future versioned freshness contract.
