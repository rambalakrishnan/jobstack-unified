## Invariants & Test Assertions
### Invariants
- **[OWD-PUBLISH]**: Owner durability acknowledgement and installation into a read view are different events. Transfer, validate, and durably install all immutable components before atomically advancing the view's domain pointer. The pointer update is bounded metadata work. Publication cannot expose partially transferred bytes.
- **[OWD-VIEW]**: A LogicalRow contains every declared domain slot and an exact version vector. Each nonzero slot embeds the complete domain document whose artifact digest and installation receipt it names. A zero slot means no publication in this view, or an explicitly inapplicable manual axis. Readers obtain one complete immutable row root.
- **[OWD-SEAL]**: A seal names a state and pins all domain revisions selected in a named read view. Its journaled seal-selection event pins the domain document digests and publication receipts before the resulting LogicalRow is registered. The row's input prefix includes that selection event, not its own later artifact-registration event.
- **[OWD-REVISION]**: A domain revision is a complete immutable snapshot, not a patch. revision=previous_revision+1 at the owner. The first revision is 1. The key (entity, domain, revision) identifies exactly one content digest. Identical retries are idempotent; different bytes under that key are an integrity conflict. Stale expected revisions or lease epochs cannot commit.
- **[OWD-OWNER]**: Every declared domain has one authenticated logical writer. Entity registration fixes its field set, authority source, writer, storage-domain identity, and publication policy. Temporary workers act through that writer's fenced transition gateway; they do not become additional owners. Each owner_domain is distinct within an entity.
- **[OWD-TIME-PROVENANCE]**: Every measurement retains clock_id, boot_id, origin, censoring, and an exact, bounded, or unavailable estimate. No cross-clock or cross-restart subtraction is permitted. Publication delay cannot be computed by subtracting arbitrary source and destination UTC annotations. Provenance and writer authorization are assigned and checked at ingestion.

`JobCrawlerValue` contains exactly:

- `acquisition`

- `ownership`
- `evaluations`
- `materials`
- `application_attempts`

Crawler ownership covers acquisition, operational processing, classifier provenance, discovery, coverage references, and crawler semantic candidate.

Product ownership covers prioritization, evaluations, application selection, product work ownership, materials, and attempt links.

Before product publication, the downstream slot is `revision=0` with `Missing(not_observed)`, explicitly meaning “no downstream revision published in this view.” The crawler does not create a pretend product revision containing null values.

Legacy `semantic_state` is retained as source evidence. It is not a shared mutable field. Any legacy display is derived from pinned crawler, product, and origin-backed attempt inputs.

### 20.4 Exact Contract 04 records

`DataDomainRevision` contains record/version, entity, registration digest, domain, owner domain, writer ID, revision, previous revision, evidence prefix, evidence refs, and complete value.

`PublicationReceipt` contains receipt identity, entity/registration/view/publisher, domain/revision/document, superseded pin, observed owner head or Missing, source prefix, installation time, publication ref, and measured/bounded/unavailable publication delay.

Installation validates complete immutable bytes before atomic pointer advance. Reordering cannot regress the pointer. Skipping visible revisions requires verified lineage. Identical delivery returns the existing receipt.

`LogicalRow` contains entity, complete registration and digest, every domain slot, and seal point. A published slot contains revision, document reference, publication reference, and complete snapshot. Zero means unpublished/inapplicable, never lost published bytes.

`SealPoint` contains seal ID/name/view, exact version vector, time, input prefix, and support. Selection is journaled before resulting row registration, avoiding self-reference.
