## Invariants & Test Assertions
### Invariants
- **[BO-THREAD]**: Allocate, enter, reset, and destroy a Page on its owning OS thread. Page, isolate-local values, DOM borrows, solver instances, and closures capturing them never cross that thread boundary. A call is synchronous: it returns a value or a typed failure, not a task handle for later polling.
- **[BO-INPUT]**: Direct property mutation, synthetic DOM event dispatch, and native browser input are different mechanisms. This catalog exposes property mutation and event dispatch explicitly; it does not label either as trusted user input. Preserve bubbles, cancelable, and composed settings and actual event observations.
- **[BO-AUTHORITY]**: Every call is bound to an admitted task/resource grant. Artifact references, scripts, node IDs, and URLs do not grant authority. Crawler acquisition and extraction cannot invoke application mutations through DOM writes, V8 evaluation, redirects, or a query POST with hidden write semantics.
- **[BO-REUSE]**: reset_for_reuse clears the native DOM registry and invalidates old DOM references while preserving the intended cookie jar. Increment the page generation before making a reset Page available again. Reuse is confined to compatible process, profile, target, and session-generation scope.
- **[BO-EVIDENCE]**: Journal the evidence needed to reconstruct a call before citing its record. Mutating calls require a durable authorized intent before native entry. Install immutable artifacts before registration. Record native returns and errors without strengthening their semantics.
- **[LIFE-IDEMPOTENCY]**: The commissioning idempotency key is scoped to the commissioning principal and immutable attempt request. Same key and request returns the same local attempt/handle; changed content under the key is rejected. Repeated Start does not launch a second logical execution.
- **[LIFE-CLAIMS]**: Execution publications contain only faithfully mapped, source-attributed claims from the commissioned subject/version. Preserve raw responses, mapping versions, declared scope, original times when available, and receipt times. An absent state is Missing, not an invented subject claim of unknown. Explicit unknown remains a valid subject claim.
- **[EXT-READ-ONLY]**: discover_jobs and extract tasks cannot execute employer/application mutations. HTTP method alone does not determine whether an operation is read-only. The crawler cannot gain application authority through an extraction extension, plan artifact, redirect, or permissive task text.
- **[EXT-RESUME]**: Resume requires a new command identity, the existing logical idempotency key/handle, explicit recovery authority, and an evidenced native checkpoint or idempotency contract for the same request and context. It preserves the same logical dispatch and journals each additional delivery.
- **[EXT-BOUNDS]**: Enforce finite local call, queue/observation, drain, cancellation-wait, and cleanup-wait bounds using registered local monotonic clocks. Admission and observation buffering are bounded; rejected work is not silently lost. An accepted queued task consumes its active observation budget.
- **[EXT-STATE-POLICY]**: Browser-state and framework-learning-state requests remain separate. Prepare records their mapping and limitations; actual realization is journaled after Start. An opaque context reference is not a Page or DOM handle and grants no authority by itself.

### 8.3 Preflight

Preflight occurs after Start, never during Describe/Prepare.

The admitted mapping must pin preflight destination, account binding, marker, scope, and policy. The destination must be permitted.

| Observation | Behavior |
|---|---|
| Authenticated marker established | Continue under policy; this is marker evidence only |
| Marker absent in valid complete observation | Native Ringmaster `SESSION_EXPIRED` report and session-expired event may be emitted |
| Marker observation incomplete | Preserve uncertainty, not definite expiry |
| Native navigation/instrumentation failure | Preserve actual failure domain |
| Active boundary reached | Stop workflow delivery and finalize locally |

`SESSION_EXPIRED` is native report content, not a new ConnectorError enum. It does not establish origin authentication facts.

### 7.4 Checkpoints
