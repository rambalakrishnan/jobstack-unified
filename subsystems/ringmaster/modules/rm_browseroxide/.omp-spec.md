### 4.2 OS-thread confinement

Allocate, enter, reset, and destroy each Page on its owning OS thread. Page, isolate-local values, DOM borrows, solver instances, and closures capturing them never cross that boundary.

A mutex does not make a Page migratable. An async task that may migrate cannot carry a native object across suspension.

Cross-thread messages contain owned bytes, immutable descriptions, diagnostic IDs, and only live HTTP-client handles whose sharing/Send semantics are established. Deserializing an ID does not restore a native object.

A native call is synchronous. A supervisor may asynchronously await its owned result without changing the primitive contract.

#### Reference: `seam-mappings/ringmaster-seam-mapping.md#5.1`

### 6.2 Per-primitive semantic obligations

| Primitive | Required semantics |
|---|---|
| `bo.client_create` | Clone-independent requires a source client and distinct pool ID. Share-process preserves actual shared pool identity. Neither mode proves independent session authority |
| `bo.http_exchange` | Acquisition-only; validate effect semantics, redirects, session epoch, sequence, and cookie order. Return follows required cookie application |
| `bo.page_create` | Allocate Page/isolate on owner thread. Missing client does not mean isolated or fresh |
| `bo.navigate` | Invalidate affected document references. Solver/iteration behavior is pinned. Navigation return is not readiness or authentication |
| `bo.from_html` | No network. Missing required resources yields `INPUTS_INCOMPLETE`; cold navigation is a separate authorized operation |
| `bo.dom_read` | Native supported CSS or rooted traversal with `selector=Missing(not_applicable)`. Unsupported grammar is explicit |
| `bo.dom_write` | One property mutation. Events are separate and never implicit |
| `bo.event_dispatch` | Synthetic DOM event with exact flags; not trusted browser input |
| `bo.v8_evaluate` | Execute in owning isolate. No V8 handle crosses threads/processes. Untrusted page/model content is not executable authority |
| `bo.assign_files` | Authorized immutable file bytes only. Assignment does not establish server acceptance |
| `bo.capture` | Use pinned native crop options. Missing geometry prevents coordinate action |
| `bo.render_verdict` | Render/acquisition classification only; Pass is not content relevance, login, or application completion |
| `bo.reset_for_reuse` | Owner-thread reset, clear registry, increment generation before reuse, preserve intended jar. Failure quarantines Page |
| `bo.page_destroy` | Owner-thread destruction. Not cancellation, rollback, or proof that remote work stopped |

The binding adds no hidden planning, healing, selector alternatives, retries, sleeps, alternate browser, or direct employer API submission.

### 6.4 BOFailure and state interpretation

`BOFailure` contains `code`, `native_entry: not_entered | entered | unknown`, `native_error: MaybeArtifact`, and sanitized nonempty `detail`.

| Code | Meaning |
|---|---|
| `WRONG_THREAD` | Reject before native entry |
| `STALE_REFERENCE` | Invalid lifetime; reject before mutation |
| `INVALID_INPUT` | Invalid argument or precondition |
| `UNAUTHORIZED` | Missing task/resource/effect authority |
| `UNMAPPED_PRIMITIVE` | Missing binding mapping, not native absence |
| `NATIVE_ERROR` | Actual native error |
| `NATIVE_TIMEOUT` | Actual native timeout evidence |
| `LOCAL_DEADLINE` | Local wait ended; native work may continue |
| `OWNER_LOST` | Native owner unavailable |
| `INPUTS_INCOMPLETE` | Required inputs absent |
| `RESOURCE_BUSY` | Ownership/concurrency policy prevents entry |
| `RESPONSE_LIMIT` | Output bound cannot be met faithfully |

Native return established maps to `returned`; definite failure to `failed`; unmapped operation to `unsupported`; unresolved entry/completion to `uncertain`.

If the owner disappears before reporting, the supervisor journals its own unresolved-call observation. It does not fabricate a subject-authored timer or return.

### 6.5 Evidence order

For potentially side-effecting calls:

1. Resolve admission, authority, mapping, and artifacts.
2. Durably record exact authorized intent.
3. Recheck owner, context, observation state, deadline, and budget.
4. Enter the native call.
5. Retain native return/error and available effects.
6. Register supporting evidence.
7. Construct, install, and register the primitive record.
8. Derive higher-level observations and claims.

A crash after entry is uncertainty, not permission to repeat the action to repair evidence.

### 7.1 HttpClient is not Page

HTTP acquisition is a first-class BrowserOxide facility. An incomplete Page render may coexist with a complete response from the correctly retained client.

Stateful and rotating sessions permit at most one jar-affecting request until redirects and cookie updates complete. Preserve client ID, pool ID, profile, session domain/epoch, request order, and cookie generation.

With process-global session storage, independent domains require separate engine processes unless namespacing is independently verified. Unknown storage is not isolated.

Cookie snapshots are recovery evidence, not permission to distribute rotating sessions or resume them after owner loss.
