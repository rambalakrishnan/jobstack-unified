## 17. Connector errors and retry safety

ConnectorError contains required:

`kind: connector_error`, `code`, `fault_domain`, `detail`, `operation_delivery`, `retry_guidance`, `retry_after`, `handle`, `evidence_refs`.

Fault domain is request, connector, native_interface, environment, policy, or unknown.

Delivery is not_dispatched, may_have_dispatched, dispatched, or not_applicable. Retry guidance is same_command_only, new_command_if_not_dispatched, operator_review, or do_not_retry.

| Code | Ringmaster interpretation |
|---|---|
| INVALID_REQUEST | Shape, field, semantic, or reference validation failure |
| UNSUPPORTED_VERSION | Unknown contract/version |
| UNAUTHENTICATED | Channel identity not established |
| FORBIDDEN | Grant absent |
| UNKNOWN_HANDLE | No authorized handle |
| UNKNOWN_PREPARATION | No authorized preparation |
| STALE_PREPARATION | Subject/configuration/mapping/artifact changed |
| IDEMPOTENCY_CONFLICT | Same command/logical key with changed content |
| UNSUPPORTED_MAPPING | Required translation/native mapping unavailable |
| PREREQUISITE_UNAVAILABLE | Required dependency unavailable |
| BUDGET_EXCEEDED | Connector operation cannot proceed within required bound |
| NOT_ADMITTED | Admission/commission not valid |
| OBSERVATION_CLOSED | Requested workflow delivery/resume after closure |
| STALE_CONTEXT | Context/session identity changed |
| RESOURCE_BUSY | Ownership/capacity policy prevents operation |
| STORAGE_UNAVAILABLE | Required durability unavailable |
| DELIVERY_UNCERTAIN | Operation may have dispatched |
| CURSOR_INVALID | Cursor identity/hash/order invalid |
| CURSOR_UNAVAILABLE | Referenced retained history unavailable |
| OBSERVATION_LOST | Required observation lost |
| RESPONSE_TOO_LARGE | Response cannot fit without prohibited loss |
| ARTIFACT_UNAVAILABLE | Authorized artifact bytes unavailable |
| NATIVE_PROTOCOL_ERROR | Cannot carry out connector operation under native protocol |
| INTEGRITY_CONFLICT | Conflicting immutable identity/content |
| INTERNAL_ERROR | Other connector implementation failure, honestly scoped |

Observed native task failure is normally evidence returned through Observe, not ConnectorError.

DELIVERY_UNCERTAIN requires may_have_dispatched and forbids fresh-command automatic retry. New-command-if-not-dispatched is allowed only for not_dispatched/not_applicable. Retrying a connector command does not authorize another native execution.

If evidence storage is unavailable, disclose it without fabricating evidence references. Do not acknowledge a durable effect that was not durably committed.
