### Invariants
- **[BO-NATIVE]**: Mapped operations enter BrowserOxide's native API directly. DOM and V8 operations must not route through CDP, Playwright, Juggler, another browser, or a shared browser adapter. Reading serialized HTML through a bridge is not evidence of direct native DOM access.
- **[BO-THREAD]**: Allocate, enter, reset, and destroy a Page on its owning OS thread. Page, isolate-local values, DOM borrows, solver instances, and closures capturing them never cross that thread boundary. A call is synchronous: it returns a value or a typed failure, not a task handle for later polling.
- **[BO-DOM]**: Native DOM observations retain frame, document, root, and node identity. Navigation, replacement, reset, and destruction invalidate affected identities before reuse. Removed/replaced nodes cannot be resurrected by reusing an ID. Reject stale references before mutation.
- **[BO-EVIDENCE]**: Journal the evidence needed to reconstruct a call before citing its record. Mutating calls require a durable authorized intent before native entry. Install immutable artifacts before registration. Record native returns and errors without strengthening their semantics.
- **[EK-NULL]**: Every null is Missing(value=null, reason=<one of the six reasons>). Empty arrays mean an established empty collection, not unknown contents. Unknown semantic states remain explicit enums; false and zero are never missing-value sentinels. manual_override requires an authenticated journaled operator decision and preserves the superseded observation.
- **[EK-TIME]**: Every Measurement and TimePoint identifies its origin, clock, and boot. Register clocks in the manifest or a clock_registered event. Persist monotonic offsets relative to that boot. A clock_registered event may atomically introduce the clock used for its own receipt timestamp. Never subtract across clock IDs or boots. UTC is annotation only.
- **[EXT-BOUNDS]**: Enforce finite local call, queue/observation, drain, cancellation-wait, and cleanup-wait bounds using registered local monotonic clocks. Admission and observation buffering are bounded; rejected work is not silently lost. An accepted queued task consumes its active observation budget.

### 9.3 Ordered transformation

1. Traverse native nodes on the owner thread; construct a separate representation without mutating live DOM.
2. Exclude script, style, noscript, link, and meta content.
3. Record iframe mount/boundary identity before omitting iframe markup.
4. Convert observed image/SVG semantics into compact markers from aria-label, role, title, or alt; never invent labels.
5. Traverse established accessible shadow roots explicitly.
6. Traverse readable frames and attach scoped sections at known mounts.
7. Emit explicit inaccessible/unobserved boundary records.
8. Preserve useful accessibility attributes and text.
9. Apply selected profile’s retention rules.
10. Normalize whitespace and serialize within the declared limit.

Ordinary clone/query semantics are not assumed to expose shadow roots. Playwright frame accessibility does not establish BrowserOxide frame accessibility.

Flattening is presentation only. Each section retains actual root/frame scope; a model selector cannot cross into another frame merely because text was flattened.

#### Reference: `seam-mappings/ringmaster-seam-mapping.md#9.4`

### 9.4 Profiles

The proposed baseline interprets source ceilings as decimal UTF-8 bytes:

| Profile | Ceiling | Retention |
|---|---:|---|
| EXTRACT | 250,000 | Structural containers, headings, tables, lists, semantic context, useful text, accessibility, accessible roots/frames |
| HEAL | 50,000 | Interactive nodes, relevant options, adjacent labels, accessibility, root/frame scope; strip layout-only wrappers and collapse wrapper chains |

The limit includes serialized reduction metadata. Reserve room for limitations and boundary records.

Overflow yields explicit partial output or a size failure. No silent truncation, broken UTF-8, or false completeness is permitted.

These are pinned Ringmaster profile settings, not universal kernel constants.

#### Reference: `seam-mappings/ringmaster-seam-mapping.md#9.5`

### 9.5 Stabilization

A selected source-derived baseline requires:

- Zero relevant in-flight network requests for 500 ms.
- Zero relevant DOM mutations for 300 ms.
- Configured hydration signatures present.

Network instrumentation, mutation observation, and rendered-text observation require actual native mappings. Contract 03 has no `bo.wait`; bounded controller observation uses mapped reads/evaluation and declared cadence.

Unavailable instrumentation produces unknown, not false. A permissive policy proceeds with structured limitations and `stabilization_partial=true`; a required policy blocks. Disabled/nonmeaningful conditions are explicitly not applicable.

These heuristics are not universal readiness or application-success predicates. Navigation invalidates prior-document observations and does not reset the task budget.
