### 8.1 RingmasterPlan

Closed object:

- `record_type: ringmaster_plan`
- `schema_version: ringmaster-plan/0.1.0`
- `steps`: nonempty ordered array of RingmasterStep

RingmasterStep contains required `step_id`, `action`, `arguments`, `recovery_policy: VersionPin`, and `limit: DurationLimit`. Step IDs are unique.

TargetRecipe contains required:

- `frame_path`: ordered native frame-mount query strings.
- `shadow_path`: ordered native shadow-host query strings.
- `strategy: css | xpath | text | role | testid`.
- `query`: nonempty string.
- `exact`: boolean.
- `max_matches`: PositiveInteger.
- `fallback_text`: nonempty string or Missing.
- `resolver_policy`: VersionPin.

Recipes are durable intent, not native node identities. They resolve anew in the current generation.

#### Reference: `seam-mappings/ringmaster-seam-mapping.md#10.1`

### 10.1 Tier 1

Tier 1 uses a pinned learning snapshot and zero model calls.

Resolution proceeds through current frame path, root path, declared strategy, bounded matches, uniqueness/eligibility checks, and generation validation immediately before mutation.

| Strategy | Mapping |
|---|---|
| CSS | Actual supported native CSS |
| Text | Pinned Ringmaster semantic text matching over native observations |
| Role | Pinned matching over observed role/accessibility semantics |
| Test ID | Pinned attribute convention |
| XPath | Only an established native/V8 mapping; otherwise unsupported |

Playwright syntax is not native CSS. One match from a truncated collection does not prove uniqueness.

Cache hits are recorded only after the configured operation/readback criterion. An action query alone is not a verified hit.

#### Reference: `seam-mappings/ringmaster-seam-mapping.md#9.3`

### 9.3 Ordered transformation

1. Traverse native nodes on the owner thread; construct a separate representation without mutating live DOM.
2. Exclude script, style, noscript, link, and meta content.
3. Record iframe mount/boundary identity before omitting iframe markup.
4. Convert observed image/SVG semantics into compact markers from aria-label, role, title, or alt; never invent labels.
5. Traverse established accessible shadow roots explicitly.
6. Traverse readable frames and attach scoped sections at known mounts.
7. Emit explicit inaccessible/unobserved boundary records.
8. Preserve useful accessibility attributes and text.
9. Apply selected profile’s retention rules.
10. Normalize whitespace and serialize within the declared limit.

Ordinary clone/query semantics are not assumed to expose shadow roots. Playwright frame accessibility does not establish BrowserOxide frame accessibility.

Flattening is presentation only. Each section retains actual root/frame scope; a model selector cannot cross into another frame merely because text was flattened.
